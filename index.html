TDK CLI

Install TDK CLI on Linux and macOS. Native Windows AMD64 installation is available with releases that include the Windows binary.

curl -fsSL https://tdk-landscape.github.io/install.sh | sh

Windows 10/11 (AMD64): install Docker Desktop in Linux container mode and Tilt for Windows, then run irm https://tdk-landscape.github.io/install.ps1 | iex in PowerShell. Windows setup guide.

Prefer npm? npm install -g @tdk-landscape/tdk-cli-core

Binaries are published at tdk-cli-releases.
